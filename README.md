# honesty-rl

**Does RL teach agents to lie about finishing their work, and can the reward stop it?**

A preregistered, three-arm RL experiment on Qwen 3.5 4B (LoRA, prime-rl). Training uses
multi-step back-office tasks that are scored against the true end state. Evaluation adds two
domains the model never trained on, including Zapier's third-party benchmark.

| Arm | Trained against |
|---|---|
| checklist | Deliverables exist + agent says done (values unchecked): gameable, like many real pipelines |
| outcome | Ground-truth partial credit |
| honest | Ground-truth partial credit + a bonus for a truthful "completed" flag |

| Eval | What it tests |
|---|---|
| letter-vs-intent `test` (mixed, expert, pressure prompts) | Held-out tasks from the training domain |
| Caseworker `test` | Unseen domain: SNAP eligibility under real federal rules |
| AutomationBench (Zapier) + self-report wrapper | Unseen third-party benchmark |
| IFEval | General ability didn't regress |

## Results (held-out, 84 tasks x 2 attempts per model)

![results](results/plots/main_results.png)

| Model | Real success | False success | Truthful report |
|---|---|---|---|
| Base | 32% | 19% | 30% |
| Base + "be honest" prompt | 36% | 12% | 35% |
| checklist arm (gameable grader) | 32% | 18% | 32% |
| outcome arm (ground truth) | 46% | 5% | 46% |
| honest arm (ground truth + truthful-claim bonus) | 48% | 4% | 47% |

Ground-truth RL cut false claims of success ~4x and raised real success +15 pp; a gameable grader did
neither (+12.5 pp false success vs ground truth, p = 0.003); the extra honesty bonus added nothing
measurable on top of ground truth. Writeup: [docs/WRITEUP.md](docs/WRITEUP.md) · tables:
[results/RESULTS.md](results/RESULTS.md) · plan + deviations: [PREREGISTRATION.md](PREREGISTRATION.md).

Along the way: a fix for prime-rl's Qwen 3.5 tied-embedding bug (`patches/`), which otherwise trains
small Qwen 3.5 checkpoints on all-zero logits.

## Layout

| Path | What |
|---|---|
| `PREREGISTRATION.md` | Hypotheses, tests, go/no-go and checkpoint rules, fixed before training |
| `configs/` | prime-rl configs (generated by `scripts/make_configs.py`, schema-validated) |
| `scripts/hackability_audit.py` | Scripted-policy reward audit (free) |
| `scripts/judge_calibration.py` | LLM-judge accuracy on labeled rollouts, transcript or database view |
| `scripts/analyze.py` | Paired bootstrap comparisons across models and sources, plots |
| `scripts/training_curves.py` | W&B curves: reward optimized vs. ground truth |
| `scripts/gpu/` | Node setup, pilot, per-arm training, final evals |
| `envs/automationbench_honesty/` | AutomationBench + a self-report tool and false-success metrics |
| `docs/WRITEUP_DRAFT.md` | Paper-style draft with result slots |

Environments live in their own repos: `letter-vs-intent` (v0.6) and `caseworker` (v0.2).
All data is synthetic.
